# The Anomaly

## Structure
- `index.html` : Fichier HTML principal.
- `css/style.css` : Fichier CSS pour le style.
- `js/script.js` : Fichier JavaScript pour l'interactivité.

## Instructions
1. Clonez ou téléchargez ce projet.
2. Ouvrez `index.html` dans un navigateur pour voir le résultat.
3. Modifiez les fichiers selon vos besoins.

## API
Le front consomme l'API NestJS du repo séparé `anomaly-api` (URL configurée dans `public/js/config.js`).
